## 📥 Descarga e Instalación (Windows / macOS)

Descargue los instaladores más recientes para Windows (`.exe` / `.msi`) y macOS (Apple Silicon / Intel `.dmg`) desde [**GitHub Releases**](https://github.com/qjr87/AiFile/releases/latest).

## ✨ Características Principales

- **🤖 Clasificación Inteligente con IA y Renombrado Masivo**: Arrastre archivos o carpetas completas; revise el plan antes de ejecutar cualquier cambio.
- **📚 Múltiples Bibliotecas y Reglas Markdown Jerárquicas**: Reglas globales, por biblioteca y por subcarpeta, con redacción asistida por IA.
- **🔌 Soporte Multi-Proveedor de IA**: Compatible con OpenAI, Anthropic Claude, Google Gemini y Ollama local (sin conexión).
- **🛡️ Operaciones Seguras y Reversibles**: Sin sobrescrituras silenciosas, detección de duplicados mediante SHA-256, deshacer en un clic y almacenamiento seguro de claves API en el llavero del sistema.
- **🌍 8 Idiomas Integrados**: Cambie de idioma al instante desde Configuración.
