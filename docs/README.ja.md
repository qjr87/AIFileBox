## 📥 ダウンロード（Windows / macOS）

[**GitHub Releases**](https://github.com/qjr87/AiFile/releases/latest) から Windows (`.exe` / `.msi`) および macOS (Apple Silicon / Intel `.dmg`) 用の最新インストーラーをダウンロードできます。

## ✨ 主な機能

- **🤖 AI 自動分類＆一括リネーム**：ファイルやフォルダをドラッグ＆ドロップするだけでサブフォルダまで自動スキャン。広告プレフィックスの除去や不要な階層の整理プランを作成し、確認後に安全に実行します。
- **📚 複数ライブラリ管理＆階層型 Markdown ルール**：全体ルール、ライブラリルール、サブフォルダルールを柔軟に設定可能。AI によるルール下書き生成にも対応。
- **🔌 マルチ AI プロバイダー対応**：OpenAI 互換 API、Anthropic Claude、Google Gemini、ローカルの Ollama（API キー不要）に対応。
- **🛡️ 安全第一のファイル操作**：同名ファイルの上書き防止、SHA-256 ハッシュによる重複検出・削除、ワンクリックの元に戻す（Undo）機能を搭載。API キーは OS のキーチェーンに安全に保存されます。
- **🌍 8 言語対応**：設定画面から日本語を含む 8 言語にいつでも切り替え可能です。
