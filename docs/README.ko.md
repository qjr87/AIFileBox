## ✨ 주요 기능

- **🤖 AI 스마트 분류 및 일괄 이름 변경**: 파일이나 폴더를 드래그 앤 드롭하면 하위 파일까지 자동 스캔하여 광고 접두사 제거, 폴더 구조 정리 및 이름 변경 계획을 생성합니다.
- **📚 다중 라이브러리 및 계층형 Markdown 규칙**: 전체 규칙, 라이브러리 규칙, 하위 폴더 규칙을 지원하며 AI 초안 자동 생성 기능을 제공합니다.
- **🔌 다양한 AI 프로토콜 지원**: OpenAI 호환 API, Anthropic Claude, Google Gemini 및 로컬 Ollama를 지원합니다.
- **🛡️ 안전한 파일 작업 및 실행 취소**: 덮어쓰기 방지, SHA-256 중복 파일 정리, 원클릭 실행 취소(Undo) 및 OS 자격 증명 관리자를 통한 안전한 API 키 보관을 지원합니다.
- **🌍 8개 다국어 지원**: 설정에서 한국어를 포함한 8개 언어를 즉시 전환할 수 있습니다.
