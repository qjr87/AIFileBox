## ✨ 核心功能

- **🤖 AI 智慧分類與批次重新命名**：支援拖入單一檔案或整個資料夾，自動掃描子目錄、清理廣告前綴與多餘嵌套，預覽確認後再執行。
- **📚 多檔案庫與階層式 Markdown 規則**：支援全域總規則、檔案庫根規則與子資料夾專屬規則，並支援一鍵讓 AI 根據目錄內容撰寫規則草稿。
- **🔌 多模型協定支援**：支援 OpenAI 相容介面、Anthropic Claude、Google Gemini 與本機 Ollama 離線模型。
- **🛡️ 安全可撤銷**：同名衝突絕不覆蓋，提供 SHA-256 指紋比對、重複檔案清理與一鍵撤銷回退；API 金鑰安全存放於系統憑證庫。
- **🌍 內建 8 種主流語言**：可在「設定 → 一般偏好」即時切換介面語言。
